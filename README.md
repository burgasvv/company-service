

# ___Приложение Корпорации, переводы и чаты___

##  Версии
* JDK 17
* Maven 3.9.9
* SpringBoot 3.3.5

## Основной стек зависимостей
* Spring Security
* Spring Web
* Spring Data JPA
* Postgresql

## Описание
        Приложение позволяет регистрировать аккаунты сотрудников, создавать чаты и организовывать денежные переводы

## Запуск приложения
* > Запустить модули приложения
* > Протестировать запросы в файле request-test.http или postman
